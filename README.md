### Recommendation-System-using-AI-HCI-Project


#### Overview

A content-based recommendation system has been developed to recommend books based on their similarity to a user-selected book. The system analyzes book titles and authors, transforming the text data into numerical vectors using TF-IDF. Cosine similarity is then used to calculate the similarity between books, allowing the system to suggest the most relevant books based on the selected title.

#### Recommended Software

* Python 3.x
* Text editor or Integrated Development Environment (IDE) such as VS Code, PyCharm, or Sublime Text.
* Command line interface (CLI) for running Python scripts.


#### Dependencies

* pandas
* scikit-learn
* numpy

These libraries are required to process data, compute similarity, and run the recommendation system effectively.


#### Instructions

1. Clone the repository to a local machine.
2. Ensure the dataset is in the correct path or location as specified in the script.
3. Install the necessary dependencies.
4. Run the Python script to begin using the recommendation system.
5. The program will display a list of sample books, prompting the user to select a book title.
6. Upon selecting a title, the system will recommend the top five similar books based on their calculated similarity.



#### Setup

1. Clone the repository from the provided link.

2. Navigate to the project folder in the terminal or file explorer.

3. Install the required dependencies.

4. Ensure the dataset is available and its path is correctly set in the script.

5. Execute the Python script to start the recommendation system.
